# 10 背景ランドマーク整理（T1）

対象: `assets/reference/background/forest1.png`（1448×1086、4:3）。陽光が差し込むファンタジーの森。
目標は広大なオープンワールドではなく、**キャラクターを置ける小さな森の広場**を、視点移動に耐える3DGSとして作ること。

## 入力画像の選定

| 画像 | 判断 |
|---|---|
| forest1 | **第一候補**。最も引きで、古木・アーチ・小道・滝・木漏れ日が1枚に収まる |
| forest2〜5 | 5枚は別生成で幾何が一致しないため、同一世界のマルチ画像入力には使わない（forest1で破綻が出た時の代替入力の候補としてのみ保持） |

## ランドマーク（forest1 の画像座標、1448×1086基準）

| ID | ランドマーク | 画像内の位置（x, y 概算） | 役割・生成時の注意 |
|---|---|---|---|
| L1 | 古木（苔むした大樹と露出した根） | 左〜中央左（330–620, 0–620） | 画面左の主役。幹の曲面と根が視点移動で崩れやすい |
| L2 | 石造アーチ（蔦と彫刻つき、左右に石柱） | 中央右（790–1110, 210–540） | 奥行きの目印。アーチの開口部の裏は未観測で、横移動で破綻しやすい |
| L3 | 小道（石段つき、アーチへ続く） | 中央下（850–1150, 560–1086） | キャラの動線。**広場の地面は小道の手前（700–1000, 750–1000）** を想定 |
| L4 | 滝と池 | 左（90–250, 390–780） | 水面は反射・透過でスプラットが苦手。破綻が出ても背景として許容 |
| L5 | 木漏れ日（光芒） | 右上（1100–1448, 0–350） | 本研究の肝。微細な光と質感は、のっぺりしたトゥーンとの差の見せ所 |
| L6 | 幻想的な花（青白く発光する小花） | 左下（0–330, 800–1000）、右（1200–1448, 730–900） | 前景の小物。細かすぎて浮遊ノイズになりやすい |
| L7 | 石碑・石柱群（彫刻つき） | 右（1190–1340, 560–760）、左奥 | 位置合わせの目印として有用 |
| L8 | 遠景（尖塔の城、岩山、霧） | 中央上（950–1110, 70–200） | 無限遠の背景。ここは破綻しても影響が小さい |

## キャラクター配置の想定（小さな広場）

- 位置: 小道の手前、画像中央やや右下（L3の手前）。左に古木、奥にアーチが見える構図。
- 後で Blender 上で `scripts/gaussian/camera_paths.json` の5視点（正面ワイド、キャラ中距離、木漏れ日ローアングル、横方向の奥行き、やや高い俯瞰）から確認する。
- 広場の足元の平坦さ（地面のコライダー）は、World Labs の collider mesh と `ground_plane_offset` で確認する。

## 生成方針

1. 入力は forest1 原画。World Labs の生成は5回まで（draft含む）。
2. draft（230クレジット）で「自動キャプション」と「ランドマークを明示した自前プロンプト」を比較し、良い方を標準モデル（約1580クレジット）で本生成する。
3. 評価観点: 5視点での破綻（穴・浮遊ノイズ・引き伸ばし・裏側の欠損）、L1〜L6の残り方、広場の地面の平坦さ。
4. 保存形式: SPZ（World Labs 標準）。PLY は export API（無料）で取得してKIRIアドオン用に保存する。
