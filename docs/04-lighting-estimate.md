# 04-A 参照画像からの光源推定（T5a）

`forest1.png`（最も引きの構図。背景3DGSの第一候補）を主対象に、太陽の向き・色温度・環境光・影の柔らかさを画像から推定した。結果は契約ファイル `assets/generated/background/lighting_estimate.json` にある。再現は `python scripts/analysis/estimate_lighting.py <assets/reference/background>`（numpy と Pillow のみ、課金APIなし）。

測定点は [docs/images/04-lighting-measure-forest1.jpg](images/04-lighting-measure-forest1.jpg)（枠が測定ボックス、黄線が光芒）。

## 結果（Phase 4-B にそのまま渡す値）

| 項目 | 推定値 | 幅 |
|---|---|---|
| 太陽の方位（+Y=アーチ方向から +X=右へ） | **約18°** | ±9° |
| 太陽の仰角 | **約24°** | ±7° |
| 太陽の色温度 | **約5050K**（色 `#ffebce`、線形RGB 1.0 / 0.83 / 0.62） | 4800〜5800K |
| 太陽:環境光（水平面の放射照度比） | **約4** | 3〜6 |
| 日陰面の色（無彩色の石が日陰で示す色） | 約5500K、中立〜やや暖色 | — |
| 太陽の見かけの直径（影の柔らかさ） | **6°**を初期値 | 3〜15° |
| 小道の日向率 | 約20%（斑の連続長は約0.2m） | — |

Blender の太陽ライトは XYZオイラー角 **(65.8°, 0°, 162.4°)**。`lighting.py` で背景の太陽向きを作るときの初期値。

見た目としては次のようになる。
- 太陽は画面の背後（アーチ側）の右上にある半逆光。カメラ側（-Y）を向く面は日陰になる。**キャラの正面は日陰で、頭頂・肩・髪の右上縁に直射と縁取り光が乗る**。
- 接地影は仰角24°から、キャラの手前左へ身長の約2.2倍（1.2mのキャラで約2.7m）伸びる。方向は +Y から見て (-0.30, -0.95)。
- 影の柔らかさは、路面の影の縁（10〜90%）が約10px（約7cm）。

## 根拠と測定

1. **光芒の向き**: 右上の光芒は垂直から約32°（右上→左下）に傾く（目視の線引き -32〜-35°、構造テンソルで -29〜-33°）。光芒は太陽の画像上の位置に収束するので、太陽は画面右上の外側（約 x=1370, y=-50）。
2. **方位・仰角**: 太陽の画像位置を、水平画角60〜80°・俯角0〜4°の仮定で3次元の向きに直す（モンテカルロ）。光軸に対する方位は約31°（右）、仰角は約24°。光軸に対して小道とアーチの方向が約14°右なので、`+Y`（アーチ方向）基準の方位は 31° − 14° ≒ 18°。
3. **色温度**: 無彩色に近い石段2か所の「日向 − 日陰」を直射光の色とみなし、色度から相関色温度を出した（5130K、4930K。中央値 約5050K）。計画の想定（5500〜6000K）より少し暖色。画像の色調補正と石の反射率が中立という仮定を含む。
4. **環境光**: 青空の隙間は約9600Kだが、日陰の石柱は約5500Kで、**日陰は青空よりずっと中立〜暖色**（樹冠と地面の反射光が効く）。ワールド光の初期値は「日陰の色」を主に、上向きに空の青を35%、下向きに地面の黄緑〜橙を50%混ぜる（`ambient.world_*_initial`）。
5. **太陽:環境光の比**: 土の日向/日陰で4.8、石段の踏面/蹴上げで3.8。水平面どうしで比べられるこの2つの平均（約4）を採用。他の石は向きや苔の反射率が混ざるので範囲（3〜6）の根拠にとどめた。
6. **影の縁と斑**: 路面の影の縁を機械測定（33〜35点、中央値10〜12px）。路面の幅1.5mを約220pxとする仮定でスケールは約6.8mm/px。

## 他の画像（forest2〜5）

観察では5枚とも太陽は右上奥、光芒は右上→左下で一致する（カメラが少し違うだけで光の設定は同じ）。構造テンソルの傾きは葉の高周波で揺れる（coherence 0.14〜0.19、forest3 は垂直に近い値で外れ）ため、数値は forest1 のみ採用し、他は定性的な整合確認にとどめた。

## 限界と次の補正

- 方位・仰角は画像1枚、画角の仮定、光芒の収束点の目視に依る。**Phase 4-B で、背景のスプラットに実際に焼き込まれた影の向きを測って補正する**（判定基準 L1: 背景の影とキャラの影の向きの差15°以内）。方位の差が15°を超える場合は、JSON の `sun.azimuth_deg_range` の端も試す。
- 背景の3DGSは World Labs が forest1 から生成するため、生成後の見かけの光はこの推定からずれうる。
- 世界座標の +Y は「キャラ設置点からアーチへ向かう方向」。統合（T4）で別の向きに確定した場合は、`sun.azimuth_deg` を `geometry_assumptions.sun_azimuth_relative_to_camera_axis_deg_median`（光軸基準 約31°）と、Phase 3 での実際のカメラ光軸の向きから再計算する。
- 色温度は画像の見た目の値（レンダー上の見え）。物理的な絶対値ではない。
