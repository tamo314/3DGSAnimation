# 06 ライティング調整とビジュアル検証（T5b・T6 / Phase 4・5）

実施日: 2026-10-20 / ブランチ: `claude/T5-lighting`（`claude/T4-integration` から派生）/ 環境: Blender 5.2.1 LTS、KIRI v5.1.0、RTX 5060 Ti
目的: 背景3DGSに焼き込まれた陽光とキャラ側の照明をできる限り一致させ（接地影・色温度・遮蔽）、5視点で3DGS特有の破綻とキャラ・背景の不整合を評価する。課金APIは使っていない。

## 1. 結論

- **方針: 背景の照明は固定（焼き込みのまま描画）し、キャラ側と影を背景に合わせる。** KIRIの Relight は使っていない（理由は6章）。
- **太陽方向**: 焼き込み影の整合テストでは**方位 約0〜24°・仰角 約15〜35°**が最も合う（T5a の写真推定 17.6°/24.2° と一致）。採用値は **方位15°・仰角26°**。一方、背景に写った太陽円盤は**方位約46°・仰角約40°**で、焼き込み影の向きとは**食い違ったまま**（背景生成物そのものの不整合）。採用方位は焼き込み影の整合の尾根の中にあり、T5a の基準 L1（背景の影とキャラの影の向きの差15°以内）を満たす。ただし写った太陽に対しては約31°ずれる。
- **色温度・明暗比**: 小道の砂の日向/日陰の焼き込み色から較正した。水平面で日向:日陰 = (3.4, 3.6, 3.2)（RGB）に対し、キャラ側ライトは (3.5, 3.5, 3.0)。
- **キャラの明るさ**: キャラ領域の輝度/周囲の輝度（線形、輪6〜40px）が T4 の 0.14〜0.33 から **0.49〜1.05** に上がり、色もR/B比が約1.4から約1.9（暖色）になった。顔や服の柄が読める。
- **接地影**: キャラの影と足元の接触AOを**背景スプラットの色に焼き込んだ**（約10.6万個、1.92M中の5.5%）。`side_depth` で小道に落ちる長い柔らかい影が見える。足は地面に付いて見える。
- **5視点とも描画できた**。3DGSの破綻は背景生成物由来のものがそのまま残る（黒点・針状の引き伸ばし・水面の透過）。照明の調整では消えない。
- 再現性: ヘッドレス再実行で5視点が**ピクセル一致**（`scripts/lighting/check_repro.py`）。

最終レンダー（PNG、1440×1080）: `experiments/T5/final/*.png`。比較: [5視点](img/06-final-5views.jpg) / [T4との比較](img/06-before-after.jpg) / [キャラ拡大](img/06-char-closeup.jpg) / [影の焼き込み](img/06-shadow-bake.jpg) / [太陽方向テスト](img/06-sun-direction-test.jpg)

## 2. 太陽方向の決め方（測定）

方位は +Y（アーチ方向）から +X（右）へ測る。3つの手がかりを背景PLYから直接測った。

| 手がかり | 方法 | 結果 |
|---|---|---|
| 焼き込み影の整合（**採用**） | 不透明スプラットのボクセル占有を作り、小道の地面スプラット8000点から候補方向へレイを飛ばして「影のはず」かを判定。焼き込み輝度が日向>影になるほど高い指標 t を出す（`shadow_test.py`） | 方位0〜24°・仰角15〜35°に尾根（t最大 約26、方位18°・仰角35°）。方位60°付近は強い負。[図](img/06-sun-direction-test.jpg) |
| 背景に写った太陽円盤 | 白飽和スプラット約4600個から塊（約2000個）を取り、キャラ頭付近からの向きの重心（`measure_sun.py`） | 方位45.8°・仰角40.3°（T4 の画像逆算 41°/38° と一致） |
| 法線とランバートの回帰 | スプラットの最小スケール軸を法線にして輝度を回帰 | R² 0.02〜0.11、方位が不安定。**不採用**（法線とアルベドの交絡） |

- 焼き込み影の整合では、写った太陽の方向（46°/40°）も t≈10〜15 と完全には棄却されない（他の多くのセルと同程度）。それでも最大は方位0〜24°。つまり**この背景は焼き込み影と太陽円盤が揃っていない**。キャラの影が落ちる方向を決めるのは焼き込み影のほうなので、そちらを採用した。
- T5a の写真推定（17.6°/24.2°）は尾根の中に入る。採用値 **方位15°・仰角26°**（尾根の中心付近、T5a に近い）。
- 影の長さ: 仰角26°ならキャラ（1.2m）の影は約2.7m、向きはカメラ側・やや左。

## 3. 光の較正（`calibrate_light.py`）

小道の砂スプラット（約54万個）の線形RGBで:

- 日陰（15〜45パーセンタイル）の平均 (0.165, 0.106, 0.058)、日向（上位10〜2%）の平均 (0.563, 0.382, 0.186)。
- 日向/日陰の比 = (3.41, 3.62, 3.20)。**アルベドに依らない**ので、この比が「太陽/環境光の色ごとの比＋1」になる。太陽は環境光より少し黄色いだけ（R:G:B ≒ 0.92:1.0:0.84）。T5a の石から出した「太陽は暖色、日陰は中立」より環境光側が暖色寄り（砂の照り返しと樹冠のため）。
- キャラ周辺（半径1m）の地面は**日向率 約19%**（ほぼ日陰に木漏れ日の斑）。

Eevee側の換算（白の拡散面、Standard変換）: 水平面の線形値 = `S·sin(el)/π`（太陽）＋ `A`（強さ1の一様環境光でA=1）。これを `lighting.py` に書いた。

| 要素 | 値 |
|---|---|
| 太陽 | 方位15°・仰角26°、角径5°、色 (0.98, 0.93, 0.72)、水平面への寄与 0.71（強さ S = 0.71π/sin26° ≒ 5.1） |
| 環境光 | 空のグラデーション（天頂 (1.0,0.97,0.92)・水平 (1.0,0.93,0.80)・天底=砂の照り返し (1.0,0.80,0.55)）、上向き水平面で 0.29 |
| 結果の日向/日陰比（水平面） | (3.5, 3.5, 3.0)（測定 3.4, 3.6, 3.2） |
| 照り返し（フィル） | カメラ側の低い方向（方位195°・仰角15°）の柔らかい平行光、影なし、暖色、正面の鉛直面に +0.15。キャラ正面が環境光だけだと暗く平板になるため。小道の日向の砂地が正面から照り返す、という意味づけ |

設定は `scripts/lighting/lighting_config.json`、実装は `scripts/blender/lighting.py`。

## 4. キャラ側と背景の照明の合わせ方（実装）

```
背景3DGS(焼き込み、Relight無効)      キャラ(Eevee)
        │                              │
        │  ← ①キャラの影・接触AOを        │  ← ②樹冠ゴボで、背景の木漏れ日の模様を
        │     スプラット色に焼き込み       │     太陽の影としてキャラに落とす
        └───────── KIRIが深度合成 ───────┘
```

### ① キャラの影を背景スプラットに焼き込む（`shadow_bake.py`）

KIRIの合成は「ガウシアンを（メッシュ深度より手前の分だけ）描き、メッシュ色の上にアルファ合成する」CPU処理（アドオンの `render_comp.py` の `alpha_composite_images`）。半透明のメッシュで背景を暗くする方法は使えない（影のメッシュの奥のガウシアンは深度で捨てられる）。そこで**キャラのメッシュ（プロキシ）で遮られるスプラットの色だけを暗くする**。

- 太陽の遮蔽: スプラットから太陽円盤（角径5°）内の10方向へキャラのBVHにレイを飛ばし、当たる割合 `frac`（柔らかい半影）。
- 接触AO: 足元（半径0.9m）のスプラットから上半球16本の余弦分布レイで近さ `ao`。
- 係数: 焼き込み色 c = ρ(a + s·lit)。lit = そのスプラットがどれだけ日向だったか（砂は日陰の砂の輝度 0.122 に対する倍率、砂以外は領域内の下位25%を日陰基準に）、K = s/a = (2.41, 2.62, 2.20)。
  遮蔽後の係数 = (1 − 0.85·ao + K·lit·(1 − frac)) / (1 + K·lit)（RGBごと、線形空間）。**すでに影だった所は暗くならず、日向だった所だけが日陰色に近づく**。
- 結果: 太陽遮蔽 48,478 個、AO 61,154 個、変更 106,353 個（平均係数 0.86）。キャッシュ付きPLY（約130MB、Git管理外）を作ってKIRIに取り込む。

この式はUnity側でスプラット単位（またはデカール）に同じ形で実装できる（8章）。

### ② 樹冠ゴボ（`lighting.add_canopy_gobo`）

太陽とキャラの間に、カメラには映らず影だけ落とす板を置く。板の不透明度は「板上の点から太陽方向の線を地面まで下ろした点」の日向度（背景の焼き込み輝度から作った地面のマップ `build_litmap.py`）。つまり**背景の地面に焼き込まれた木漏れ日の模様を、同じ太陽方向でキャラの体にも落とす**。平均透過率は0.43（下限0.2、葉の透過を想定）。

- 太陽が背面側（半逆光）なので、ほとんどの視点でキャラの正面は環境光＋フィルだけで照らされ、太陽の寄与は縁と背面に限られる。ゴボの効果（斑）は主に背面・側面に出るため、最終画像では目立たない（太陽だけの診断では正面は真っ黒）。
- 日向度マップの作り方の注意: 小道の砂は絶対輝度（日陰の砂の約3.4倍を日向）、砂以外は局所コントラスト。

### 視点ごとの所見

| 視点 | 3DGS特有の破綻（背景由来） | キャラと背景の不整合 | 改善余地 |
|---|---|---|---|

| **side_depth**（横方向の奥行き） | 右上の柵が薄く透け、板の隙間に光芒が重なって読みにくい。それ以外は良好 | **接地影が最もはっきり見える**: キャラから手前（カメラ側・左）へ伸びる長い柔らかい影が砂の斑を覆う。足は付いて見える。キャラが小さく、質感差は気にならない | 影の濃さが一様でやや「エアブラシ」状（元の斑模様の中で影の縁が見えない） |
| **high_oblique**（俯瞰） | 池の水面は透過気味で黒点と筋が多い（T4と同じ）。右上の壁・草に針状の引き伸ばし、右側の石壁がぼける | キャラは小さいが明るさ・色がなじみ、頭の上から見た形も読める。足元の影も見える | 水面と引き伸ばしは背景の再生成または後処理の対象（Phase 6） |

### 全体の評価

1. **ライティングの不整合は大きく改善した**（キャラ/周囲の輝度比 0.14〜0.33 → 0.49〜1.05、色が暖色に）。接地感（影・AO）も出た。
2. **残っている不整合**
   - 背景自身の不整合（写った太陽の向きと焼き込み影の向き）が、太陽の見える視点（dappled_low）でキャラとの不整合として表に出る。
   - キャラの質感とエッジが背景より平坦・鮮明で、「きれいに照らされた切り抜き」に見える（光の整合では解決しない部分）。
   - キャラの正面が半逆光でほぼ環境光だけになるため、陽光を浴びている印象は縁と背面にしか出ない（正面に太陽を当てると焼き込み影と矛盾する）。
3. **3DGS特有の破綻は照明の調整では変わらない**（黒点・針状の引き伸ばし・水面の透過・光の帯のにじみ）。いずれも背景生成物由来で、視点を変えても同じ位置に出る。

## 6. 試したことと失敗

| 試み | 結果 |
|---|---|
| **KIRI Relight（`r2_relight`）＋ `r2_shadows` でキャラの影を落とす** | T3と同じくRelightを有効にして影を使う設定で試すと、背景全体が法線とライトで再ライトされる（二重照明）。強さ0.01で真っ暗、0.1〜0.3で全体が明るく暖色にずれた。背景の焼き込み色を保てないので不採用（Relight無効のまま影だけ使えるかは未確認） |
| **KIRIのシャドウプロキシ（ガウシアン→メッシュの影、`r2_shadow_proxy`、30万枚・cutoff0.5）** | キャラがやや暗くなるだけで、木漏れ日の斑にならず制御できない。不採用 |
| 半透明のメッシュ（影カード）で背景を暗くする | KIRIの合成がガウシアン over メッシュのため、深度で背景が捨てられて効かない |
| 法線ランバート回帰で太陽方向 | R² 0.02〜0.11、不安定。不採用 |
| キャラ内側・表面3cm以内の背景スプラットの除去（`--cull 0.03`、2,136個） | 高俯瞰の足元の見た目にほぼ差が出ず、既定では無効（オプションのみ残す） |
| 太陽をキャラ背面に置いたまま環境光だけ | キャラ正面が暗く平板（T4と同じ）。暖色の照り返しフィルを足して解決 |
| 画像ビューアで左右に並べた比較 | 同じ画像でも右側が霞んで見える表示差があった。判断は `char_bg_stats.py` の数値と単独画像で行った |

## 8. Unity側（実行環境）への含意

ユーザー承認済みの方針どおり、KIRIでの見た目をUnity側の見た目の参照にし、実行環境は別設計にする。この検証から持ち込める設計要素:

1. **背景は焼き込みのまま描く**（再ライトしない）。ライトの定数は `lighting_config.json`（太陽の向き・色・強さ比、環境光の色）。Unityでは Directional Light＋グラデーション環境光（SH L1〜L2のプローブ）で再現できる。
2. **キャラの影の背景への落とし方**: スプラット単位の係数 (1 − k·ao + K·lit·(1−frac)) / (1 + K·lit) を、キャラのプロキシ（カプセル・簡易メッシュ）とのレイ・距離で計算し、スプラットの色に掛ける（`lit` は静的に前計算できる）。または地面デカール。動くキャラには、スプラット単位の前計算を地面付近のスプラットだけに絞って毎フレーム更新するのが現実的。
3. **木漏れ日**: 地面の日向度マップ（`litmap.npz`）をそのままDirectional Lightのクッキー（太陽方向に投影するテクスチャ）にできる。キャラが動くと斑の中を通る。
4. **フィル**: 影なしの第2のDirectional Light、または環境プローブの前方成分。

## 9. 参照研究（Phase 6）で改善できそうな点

実装済みの研究を検証したわけではなく、今回の限界から出てきた仮説。

- **法線の取れる3DGS**: 今回、スプラットの最小スケール軸は法線として不安定だった（回帰R²≈0.1）。法線・深度を正則化した手法（面状ガウシアン系）で背景を作れば、再ライティングの精度が上がる可能性がある。
- **逆レンダリング・再ライティング系**: 焼き込みをアルベド・法線・可視性に分けられれば、背景も太陽の向きに反応できる。今回は焼き込み輝度から日向度を推定しただけ（ヒューリスティック）。
- **動く物体の影の落とし方**: スプラット単位の遮蔽判定は今回の近似（実質は影の係数）。可視性（遮蔽）を学習・前計算する研究があれば、より正確な影が出せる可能性がある。
- **外れ値の掃除**: 黒点（暗い孤立スプラット）、引き伸ばされた針状スプラット、半透明の水面は背景生成物のまま。不透明度・スケールの正則化やプルーニングの後処理で改善できる可能性がある。
- **太陽円盤・光芒の扱い**: 光芒と太陽の光条は焼き込みの幾何として存在し、視点で形が崩れうる。実行環境では背景から分けて別レイヤー（スカイボックスやビルボード）にするのも案。
- **キャラの質感を背景のレベルに**: 3DGS表面の微細質感（研究ゴール）を、キャラの描画へ持ち込む検証（Phase 6の本題）。今回のキャラは平坦なテクスチャで、背景との質感差が最も目立つ不整合として残った。
